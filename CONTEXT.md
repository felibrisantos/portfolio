# brigagao.dev

A personal portfolio: one page, two languages, read mostly by recruiters
deciding in under a minute whether to go further.

## Language

### Clients and claims

**Nameable client**:
A client whose name may appear where a reader can see it. A client can be
worked for without being nameable; only nameable clients appear in copy, in
metadata or in a commit message.
_Avoid_: public client, disclosed client

**Project access**:
The answer a project card gives about whether a reader can reach the work.
Every card answers it — with a link when the work is reachable, and with a
statement when it is not — so the slot never reads as nothing to show.
_Avoid_: project link, visibility

### Copy

**Positioning**:
The site's single claim about what Felipe does, stated in the hero. The short
form exists so the mobile hero's action survives the first fold.
_Avoid_: tagline, headline, bio

**Intent**:
The purpose a call to action serves. The copy holds one label per intent, not
one per placement, so the same action reads the same everywhere.
_Avoid_: button label, CTA text

### Layout

**Layout family**:
The single layout shape a section uses. One family per section, and a section
does not mix two.
_Avoid_: layout type, section style

**Featured entry**:
The first project, rendered at the full width of the work grid.

**Theme inversion**:
The page's one dark surface. It is deliberately the only one, and it carries
its own accent because the primary fails contrast against it.
_Avoid_: dark mode, dark section

### Colour

**Ink**:
The single near-black that carries every rule and border on the light page and
the inverted surface itself. One value, because they are the same black.
_Avoid_: black, foreground

**Primary**:
The brand blue, used for accents, actions and every offset shadow.
_Avoid_: accent, brand blue, navy
